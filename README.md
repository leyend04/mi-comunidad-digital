# Mi Comunidad Digital — versión minimalista

Página web estática optimizada para celular, con cuatro accesos principales, dos opciones adicionales y recursos educativos. Conserva la búsqueda, el directorio, los enlaces y la opción de añadir un acceso directo al inicio del celular.

## Publicar en GitHub Pages

1. Crea un repositorio público llamado `mi-comunidad-digital`.
2. Sube **el contenido de esta carpeta** a la raíz del repositorio. `index.html` debe quedar en la raíz.
3. En GitHub: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
4. Tu sitio tendrá una dirección similar a `https://TU-USUARIO.github.io/mi-comunidad-digital/`.
5. Si ya habías publicado la versión anterior, reemplaza los archivos por estos y confirma los cambios (**Commit changes**). Puede ser necesario recargar la página para actualizar la versión instalada.

## Editar información

Todos los textos y recursos comunitarios están en `datos.js`. Solo publica información real con consentimiento de las personas involucradas. Los contenidos marcados `demostracion: true` son ejemplos de uso, no negocios o actividades confirmados. Comprueba que el enlace `infografiaUrl` se abra sin iniciar sesión.

## Añadir acceso directo

En Android, abre el menú de Chrome y selecciona «Instalar aplicación» o «Añadir a pantalla principal». En iPhone, usa el botón Compartir de Safari y «Añadir a pantalla de inicio». No se necesita cuenta ni instalación desde una tienda.

La web utiliza HTML, CSS y JavaScript, funciona en GitHub Pages y conserva el caché básico sin conexión para la interfaz (no garantiza acceso sin conexión a los enlaces externos).
